Put the MySQL Connector/J JAR in this folder (optional but recommended), for example:

    mysql-connector-j-8.4.0.jar

Download: https://dev.mysql.com/downloads/connector/j/
(choose "Platform Independent", download the ZIP, extract it, and copy the .jar file here)

Then add it to the Eclipse Build Path - see README.md, section 9.
The JAR is NOT included in this project because it is a separate download.
